The routing layer between your prompt and your AI agent.

Not every task deserves the biggest model. codemux reads each prompt, decides the right model · effort · mode, and wraps the change in git-level guardrails — so trivial edits stay cheap, hard work gets real horsepower, and secrets never leak.

    Guardrails, before and after

    Pre-hooks catch problems before the agent runs; post-hooks clean up after. Both are live below.

    codemux scan pre-hook

    Scans changed files for secret-shaped strings and refuses to hand them to an agent. Findings are always masked.

    codemux guard pre-hook

    Refuses direct edits on a protected branch, so an agent is forced onto a feature branch first.

    protected: main, master, production

    04

    Get started

    Node ≥ 20. Free and open source, MIT.

    STEP 1

    Install

    One curl line, or clone and build from source.

    STEP 2

    Init

    codemux init detects your stack and scaffolds .codemux/.

    STEP 3

    Route & guard

    Wire route, scan, guard, and post into your agent or git hooks.

    # install from source (published to npm in a later release)
curl -fsSL https://raw.githubusercontent.com/vibhusharma101/codemux/main/install.sh | sh

# in any repo
codemux init
codemux route "add a CSV export endpoint"   # → sonnet-5 / high / /plan
codemux guard # refuse edits on main
codemux scan  # secrets check
codemux post  # scoped format + lint + tests
    the one idea

    Model choice shouldn't be a habit or a guess. codemux makes it an explicit, overridable, testable decision — and fences every change with the same guardrails a careful reviewer would.
